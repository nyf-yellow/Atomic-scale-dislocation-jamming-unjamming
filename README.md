# Data and Code for  
"Atomic-scale mechanisms underlying dislocation jamming-unjamming transition in three-dimensional dislocation networks"

This repository contains the molecular dynamics simulation files and processed datasets supporting the manuscript.

## Contents

### LAMMPS/
LAMMPS input files

### DislocationDensity/
Time evolution of dislocation density.

### StrainEvolution/
Strain evolution data under different loading conditions.

### StrainRate.zip/
Data used for stress-strain rate scaling analysis.

## Software

The simulations were performed using LAMMPS, and atomic structures were analyzed using OVITO.
